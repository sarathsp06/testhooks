## Run it in one line

Locally, with no database:

```bash
docker run -d --name testhooks -p 8080:8080 -e DATABASE_URL=memory ghcr.io/sarathsp06/testhooks
```

With PostgreSQL, for shared or long-running instances:

```bash
curl -fsSL https://raw.githubusercontent.com/sarathsp06/testhooks/main/deploy/docker-compose.yml | docker compose -p testhooks -f - up -d
```

Then open `http://localhost:8080`. See [Installation](getting-started/installation/) for the binary installer and other options.

## Everything for webhook development

<CardGrid>
	<Card title="Reach localhost" icon="laptop">
		Browser mode forwards with `fetch()` from your tab, so it reaches localhost, Docker and anything else your machine can see. No CLI, daemon or tunnel.
	</Card>
	<Card title="Private by default" icon="seti:lock">
		In browser mode, payloads are relayed over WebSocket and never written to the server's disk.
	</Card>
	<Card title="Live inspection" icon="rocket">
		Every request appears the instant it arrives: headers, query, body with syntax highlighting. Copy as cURL, export as JSON or CSV.
	</Card>
	<Card title="Script transforms" icon="pencil">
		Reshape payloads with JavaScript, Lua or Jsonnet, sandboxed in WASM, before they are forwarded.
	</Card>
	<Card title="Forward and mock" icon="random">
		Forward to any URL, sync or async with retries, and script the exact response the sender gets back.
	</Card>
	<Card title="Verify signatures" icon="approve-check">
		Check Standard Webhooks signatures from Sparrow, Svix and others, and reject bad ones like a real receiver.
	</Card>
</CardGrid>
